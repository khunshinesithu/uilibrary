# UI Library

My collection of UI components. Come here, find a component, and copy it into a project.

## Components

| Component | Folder |
| --- | --- |
| Receipt Printer | [`components/receipt-printer`](components/receipt-printer) |

## How it is organised

- Each component has its own folder inside `components/`.
- The code is saved exactly as it was found.
- Each folder has a `README.md` that lists what the component needs (npm packages, helper files, images).
